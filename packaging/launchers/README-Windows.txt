BMW Service Manager for Windows
===============================

Nothing else needs installing: this folder has everything, including its own copy of Python.

To start it
  1. If you haven't already, unzip the download: right-click the .zip file,
     choose Extract All..., then Extract. Use the extracted folder, not the .zip.
  2. Double-click "Start BMW Service Manager" (Start BMW Service Manager.bat).
  3. The first time, Windows may say "Windows protected your PC". Click More info,
     then Run anyway. If Windows Firewall asks about python.exe, tick Private networks
     and click Allow: that's how it finds the car.
  4. A black window opens and your web browser shows BMW Service Manager.
     Leave the black window open while you use it; close it to stop.

To try it without a car, double-click "Try without a car" instead: it starts with a
pretend car, so you can look around before plugging anything in.

Connecting to the car: see "Connecting to the car" at
https://github.com/devttys1/bmw-service-manager
