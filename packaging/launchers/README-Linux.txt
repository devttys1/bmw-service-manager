BMW Service Manager for Linux
=============================

Nothing else needs installing: this folder has everything, including its own copy of
Python (for 64-bit Intel/AMD and 64-bit ARM, such as a Raspberry Pi 4 or 5).

To start it
  1. Extract the download (most file managers: right-click > Extract Here), or in a terminal:
       tar xzf BMW-Service-Manager-Linux.tar.gz
  2. Run start-bmw-service-manager.sh: double-click it and choose Run in Terminal, or in a
     terminal:
       "BMW Service Manager/start-bmw-service-manager.sh"
  3. Your web browser shows BMW Service Manager (if it doesn't open by itself, open the
     address the terminal shows). Leave the terminal open while you use it; Ctrl+C stops it.

To try it without a car, run try-without-a-car.sh instead: it starts with a pretend car.

Connecting to the car: see "Connecting to the car" at
https://github.com/devttys1/bmw-service-manager
